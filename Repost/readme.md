# Repost — HTML Template

Modern responsive HTML template for a content community, blog, news portal or social publishing platform. Includes 21 ready-made pages, light and dark themes, adaptive layouts, user profiles, channels, posts, comments, messages and account settings.

Built with semantic HTML5, modern CSS3 and JavaScript. Nunjucks and Vite are used for component-based development and production builds. All files in this package are ready for further integration with any CMS or backend.

# Repost — HTML-шаблон

Современный адаптивный HTML-шаблон для контентного сообщества, блога, новостного портала или социальной платформы. В комплекте 21 готовая страница, светлая и тёмная темы, профили пользователей, каналы, публикации, комментарии, сообщения и настройки аккаунта.

Разработан на семантическом HTML5, современном CSS3 и JavaScript. Для компонентной разработки и production-сборки используются Nunjucks и Vite. Все файлы готовы к дальнейшей интеграции с любой CMS или backend-системой.
